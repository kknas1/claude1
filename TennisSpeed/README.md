# 테니스 공 스피드 측정 (TennisSpeed)

아이폰 사파리에서 바로 실행되는 PWA. 카메라로 테니스 공을 추적해서 속도를 km/h로 측정합니다. 빌드 단계 없는 단일 `index.html` 한 파일.

## 아이폰에서 바로 쓰는 법

1. 이 저장소를 GitHub Pages로 켭니다 (아래 "배포" 항목 참고).
2. 아이폰 사파리에서 배포된 URL을 엽니다. 예: `https://<user>.github.io/<repo>/TennisSpeed/`
3. `카메라 시작` 버튼 탭 → 권한 허용.
4. 후면 카메라가 켜집니다. 공이 들어올 위치를 잡습니다.
5. `보정` 버튼 → 화면에서 **이미 길이를 아는 두 점**을 탭합니다.
   - 예: 코트 베이스라인 폭 10.97m, 서비스 박스 가로 4.115m, 1m 자, 라켓 길이 약 68.5cm 등
6. 실제 거리 입력 (cm 또는 m) → `확인`. 보정 완료.
7. 공이 화면 안으로 들어오면 초록 원으로 추적되고 상단에 km/h가 표시됩니다.
8. 홈 화면에 추가 (공유 → 홈 화면에 추가) 하면 전체화면 앱처럼 동작합니다.

## 작동 원리

- `getUserMedia({ facingMode: 'environment' })`로 후면 카메라 스트림 획득
- 매 프레임 `<video>`를 320×N 오프스크린 캔버스에 다운스케일 후 픽셀 데이터 추출
- **움직임 게이팅**: 직전 프레임 대비 RGB가 충분히 변한 픽셀만 후보로 (정지한 카트의 공 더미, 코트 라인 등 제외)
- 각 픽셀을 RGB→HSV 변환해 노란-녹색 범위(기본 H:35–85, S≥30%, V≥35%)로 필터링
- 일치 픽셀의 중심점(centroid)을 공 위치로 사용
- 이전 프레임 위치와 현재 위치의 픽셀 거리 × `metersPerPixel` ÷ Δt → m/s → ×3.6 → km/h
- 노이즈 안정화를 위해 **최근 1초 내 최대 속도**를 현재 속도로 표시. 모든 속도의 단순 평균도 별도 표시
- 최대값은 별도 추적 · `리셋` 버튼으로 초기화

`metersPerPixel`과 슬라이더 설정은 `localStorage`에 저장되어 다음 방문 시 복원됩니다.

## 정확도와 한계

| 상황 | 정확도 |
|---|---|
| 아마추어 랠리 (40–100 km/h), 카메라가 공의 진행 방향에 직각 | 양호 |
| 공이 카메라 방향으로 직접 다가오거나 멀어짐 | 크게 과소측정 (2D 투영이므로) |
| 프로 서브 (180+ km/h) | 30 fps에선 모션 블러 + 픽셀 점프로 부정확 |
| 노란 옷, 잔디, 다른 노란 물체 | 오검출 가능 → 슬라이더로 색상 범위 조정 필요 |

**팁**: 카메라를 공의 궤적과 직각이 되도록 측면에 두고, 보정 거리는 **공이 움직이는 평면 위**의 거리로 측정해야 정확합니다.

## 배포 (GitHub Pages)

레포 Settings → Pages → Source: `Deploy from a branch` → Branch: `main` (또는 원하는 브랜치), Folder: `/ (root)` → Save.

배포 후 1–2분 뒤 다음 URL에서 접근 가능합니다:

```
https://<github-username>.github.io/<repo-name>/TennisSpeed/
```

`localhost` 외에는 **HTTPS 필수**입니다 (카메라 권한 조건). GitHub Pages는 자동 HTTPS.

## 로컬 테스트

```sh
# 저장소 루트에서
python3 -m http.server 8000
# 또는
npx serve .
```

`http://localhost:8000/TennisSpeed/` 접속. `localhost`는 HTTPS 없이도 카메라 권한이 허용됩니다.

아이폰에서 로컬 테스트하려면 HTTPS 터널이 필요합니다:
- `ngrok http 8000` → HTTPS URL 사용
- 또는 `mkcert`로 로컬 HTTPS 인증서 발급
