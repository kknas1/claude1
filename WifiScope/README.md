# 와이파이 스코프 (WifiScope)

Wi-Fi 신호 품질을 **눈으로 보는** 모바일 웹앱 (PWA).
공중에 떠 있는 Wi-Fi 신호를 색상으로 시각화하는 AR 앱 컨셉을 웹으로 구현했습니다.

**실행:** https://kknas1.github.io/claude1/WifiScope/ (기본 브랜치 머지 후 GitHub Pages 반영)

## 기능

| 탭 | 기능 |
|---|---|
| **측정** | 핑·지터·다운로드·업로드 실측 → 0~100 품질 점수 게이지, 연결 정보(ISP·지역·서버) |
| **AR** | 제자리에서 폰만 돌려도 **공간에 퍼진 신호가 바로 보임** — 자이로 3D 투영으로 공중 신호 입자 필드·전파 파동 링·물결 네온 스트림·바닥 그리드를 실제 공간에 고정된 것처럼 표시(전부 현재 신호 색으로 실시간 반응). 걸으면 걸음 감지로 지나온 경로에 궤적이 남음. 핑 스파크라인, 스냅샷 저장 |
| **평면도** | 평면도 사진 업로드 → 내 위치 탭 → 자동 측정 → IDW 보간 히트맵(보라=약함·노랑=보통·초록=좋음), 측정점 관리 |
| **기록** | 측정 이력·요약 통계, 데이터 초기화 |

**내보내기:** 히트맵 PNG · 측정점/기록 CSV · PDF 리포트(인쇄 화면에서 "PDF로 저장")

## 신호 등급

- 🟢 **좋음 (70~100)** — 강한 신호 · 4K 스트리밍/화상회의 원활
- 🟡 **보통 (40~69)** — 웹서핑 가능 · 대용량 전송 느림
- 🟣 **약함 (0~39)** — 끊김 잦음 · 공유기 위치 개선 필요

## 원리와 한계 (정직 고지)

브라우저는 보안 정책상 **RSSI(dBm)·SSID 목록·채널 정보를 웹앱에 제공하지 않습니다.**
따라서 이 앱은 Cloudflare 속도 측정 엔드포인트(`speed.cloudflare.com`)로
핑/다운로드/업로드를 **실측**하여 체감 품질 점수를 계산합니다 — 실제 사용 경험(끊김·속도)을
기준으로 한 지표라 커버리지 진단 목적에는 충분히 실용적입니다.

- 측정 시 테스트용 무의미 데이터만 송수신 (간단 약 5MB · 정밀 약 30MB)
- AR 뷰는 자이로(기기 자세) + 걸음 감지 기반 **의사-AR**입니다 — 바닥 그리드·궤적이 실제 바닥에 붙은 것처럼 투영되지만, ARKit/ARCore류 SLAM 공간 추적이 아니므로 위치 오차가 누적될 수 있습니다 ("궤적 리셋"으로 초기화)
- 카메라 영상은 표시·스냅샷 용도로만 사용, 저장·전송 없음

## 개인정보

평면도·측정점·기록은 전부 **기기 브라우저(localStorage)에만 저장**되며 서버로 전송되지 않습니다.

순수 HTML/CSS/JS (빌드 도구 없음) · Canvas 2D 히트맵(IDW 역거리 가중 보간) ·
getUserMedia · Web Share API · PWA(오프라인 셸 캐시)
